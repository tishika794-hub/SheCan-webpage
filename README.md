# SheCan Webpage

## Overview
Welcome to the **SheCan** webpage repository! This project showcases a modern, responsive website dedicated to empowering and inspiring women in technology and beyond.

## Project Description
SheCan is a platform that celebrates women's achievements, provides resources, and builds a supportive community. The website features information about women leaders, success stories, and opportunities for growth and collaboration.

## Getting Started

### Prerequisites
- A modern web browser
- Basic knowledge of HTML, CSS, and JavaScript

### Installation
1. Clone the repository:
```bash
git clone https://github.com/tishika794-hub/SheCan-webpage.git
cd SheCan-webpage
```

2. Open the webpage locally:
   - Simply open `index.html` in your web browser, or
   - Use a local server for better functionality:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```

3. Visit `http://localhost:8000` in your browser
